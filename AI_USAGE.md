# AI Usage

AI tools were used during the development of this project for the following tasks:

- **LLD design:** Discussing the design and flow of the application.
- **Skeleton generation:** Creating the initial structure for services, repositories and controllers.
- **Test case generation:** Preparing test cases for different scenarios and requirements.
- **Test data generation:** Creating sample data for testing the screening rules.
- **Logic implementation:** Getting help with implementing parts of the application logic.

## Tools Used

- OpenCode
- Claude

## Key Prompts

1. **Task 1 – LLD and application flow**

   I shared the given use case scenario and asked the AI to help prepare the LLD for Task 1.

   Some of the suggested classes and service flows were becoming too complex. I wanted to avoid unnecessary layers and over-modelling, as that would make the code harder to understand and maintain.

   I asked the AI to explain the complete claim-to-fraud-alert flow and, based on that, simplify and finalise the classes and API design.

2. **Task 1 – Project skeleton and tests**

   Using the finalised classes and API design, I asked the AI to generate the initial project skeleton.

   I also used it to prepare general test cases and scenario-based test cases for the requirements mentioned in the assignment.

3. **Task 2 – Design and implementation**

   I followed a similar approach for Task 2, using AI assistance for the design, project structure, test cases and implementation.
